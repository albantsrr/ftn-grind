## Why Archive?

These files were consolidated to:
1. **Reduce token usage** - Eliminate duplicate content across multiple files
2. **Improve maintainability** - Single source of truth for each topic
3. **Enhance discoverability** - Comprehensive guides are easier to find and use
4. **Preserve history** - Original files retained for reference
