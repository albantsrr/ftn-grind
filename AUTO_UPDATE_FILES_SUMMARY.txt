🔧 CE QU'IL VOUS RESTE À FAIRE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Installer les dépendances npm
   └─ cd frontend && npm install

2. Générer les clés de signature
   └─ npm run tauri signer generate -- -w ~/.tauri/fortiflow.key

3. Configurer les secrets GitHub
   └─ TAURI_SIGNING_PRIVATE_KEY (contenu de ~/.tauri/fortiflow.key)
   └─ TAURI_SIGNING_PRIVATE_KEY_PASSWORD (si mot de passe défini)

4. Ajouter la clé publique dans tauri.conf.json
   └─ Remplacer "YOUR_PUBLIC_KEY_HERE"

5. Commit et push
   └─ git add . && git commit -m "feat: Add auto-update" && git push
